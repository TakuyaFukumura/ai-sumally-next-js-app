# AI要約アプリ 仕様書

## 1. 概要

本アプリは、既存のNext.jsアプリケーションに対してAI要約機能を追加するものです。
ローカルで起動しているOllama（LLM推論サーバー）と連携し、入力された文章を要約してデータベースに保存します。
保存された要約と原文は画面から参照でき、要約の再生成も可能です。

---

## 2. 目的・背景

- ローカル環境で手軽に動作するAI要約ツールを提供する
- Ollamaを活用することで、クラウドAPIを使わずにプライバシーに配慮した要約処理を実現する
- 要約履歴を管理し、再生成・比較ができる環境を整える

## 4. 機能要件

### 4-1. 文章の入力と要約生成

- ユーザーがテキストエリアに原文を入力できる
- 「要約する」ボタンを押すとOllamaに要約リクエストを送信する
- 要約完了後、原文と要約文をデータベースに保存する
- 保存後、画面上に要約結果を表示する

### 4-2. 要約履歴の一覧表示

- 保存済みの要約一覧をページ上に表示する
- 各エントリには以下の情報を表示する
  - 要約文
  - 原文（折りたたみ表示など）
  - 作成日時
  - 最終更新日時

### 4-3. 要約の再生成

- 既存の要約エントリに対して「再生成」ボタンを提供する
- 再生成時に任意の指示文（プロンプト追記）を入力できるテキストフィールドを表示する
  - 例：「箇条書きで要約してください」「英語で要約してください」
- 指示文はオプション（空でも再生成可）
- 再生成した要約は同じエントリに上書き保存する（原文は変更しない）

### 4-4. ローカル環境でのデフォルト動作

- デフォルト設定でローカルPCで動作する
- Ollamaの接続先はデフォルトで `http://localhost:11434` とする
- 使用モデルはデフォルトで `llama3` とする（環境変数で変更可能）
- データベースファイルは既存の `data/app.db` を引き続き使用する

## 5. 非機能要件

| 項目 | 内容 |
|------|------|
| 動作環境 | ローカルPC（Node.js 20.x以上） |
| 対応ブラウザ | Chrome最新版、Firefox最新版 |
| レスポンス | 要約処理中はローディング表示を行う |

| セキュリティ | ローカルPCでの単一ユーザー利用を前提とし、CORSは設定しない。書き込み系APIでは Origin / Referer 検証またはCSRF対策を実装する |

## 6. データベース設計

既存の `data/app.db`（SQLite）に新テーブル `summaries` を追加します。

### `summaries` テーブル

| カラム名 | 型 | 説明 |
|----------|----|------|
| `id` | INTEGER PRIMARY KEY AUTOINCREMENT | 主キー |
| `original_text` | TEXT NOT NULL | 原文 |
| `summary_text` | TEXT NOT NULL | 要約文 |
| `instruction` | TEXT | 再生成時の指示文（任意） |
| `model` | TEXT NOT NULL | 使用したOllamaモデル名 |
| `created_at` | DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP | 作成日時 |
| `updated_at` | DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP | 最終更新日時（更新時に CURRENT_TIMESTAMP を設定） |

## 7. API設計

### POST /api/summaries

新規要約を生成してデータベースに保存します。

**リクエストボディ:**

```json
{
  "originalText": "要約対象の原文テキスト"
}
```

**レスポンス（成功時）:**

```json
{
  "id": 1,
  "originalText": "要約対象の原文テキスト",
  "summaryText": "AIが生成した要約文",
  "model": "llama3",
  "createdAt": "2026-01-01T00:00:00.000Z",
  "updatedAt": "2026-01-01T00:00:00.000Z"
}
```

---

### GET /api/summaries

保存済みの要約一覧を取得します。

**レスポンス（成功時）:**

```json
[
  {
    "id": 1,
    "originalText": "原文テキスト",
    "summaryText": "要約文",
    "instruction": null,
    "model": "llama3",
    "createdAt": "2026-01-01T00:00:00.000Z",
    "updatedAt": "2026-01-01T00:00:00.000Z"
  }
]
```

---

### PUT /api/summaries/[id]

指定した要約を再生成して更新します。

**リクエストボディ:**

```json
{
  "instruction": "箇条書きで要約してください（任意）"
}
```

**レスポンス（成功時）:**

```json
{
  "id": 1,
  "originalText": "原文テキスト",
  "summaryText": "再生成された要約文",
  "instruction": "箇条書きで要約してください",
  "model": "llama3",
  "createdAt": "2026-01-01T00:00:00.000Z",
  "updatedAt": "2026-01-01T12:00:00.000Z"
}
```

## 9. Ollama連携仕様

- Ollama API エンドポイント: `http://localhost:11434/api/generate`
- 使用モデル: 環境変数 `OLLAMA_MODEL` で指定（デフォルト: `llama3`）
- Ollama接続先URL: 環境変数 `OLLAMA_BASE_URL` で指定（デフォルト: `http://localhost:11434`）
- リクエスト形式（Ollama Generate API）:

```json
{
  "model": "llama3",
  "prompt": "以下の文章を日本語で要約してください:\n\n{原文}",
  "stream": false
}
```

- 再生成時のプロンプト例（指示文あり）:

```
以下の文章を日本語で要約してください。
追加指示: 箇条書きで要約してください

{原文}
```

## 11. セットアップ手順

### 前提条件

- Node.js 20.x以上
- Ollamaがインストールされ、ローカルで起動していること

### Ollamaのセットアップ

1. [Ollama公式サイト](https://ollama.com/)からOllamaをインストール
2. Ollamaを起動:
   ```bash
   ollama serve
   ```
3. 使用するモデルをダウンロード:
   ```bash
   ollama pull llama3
   ```

### アプリケーションのセットアップ

1. 依存関係をインストール:
   ```bash
   npm install
   ```

2. 環境変数ファイルを作成（任意）:
   ```bash
   cp .env.local.example .env.local
   ```
   デフォルト設定のままで動作するため、変更が必要な場合のみ編集してください。

3. 開発サーバーを起動:
   ```bash
   npm run dev
   ```

4. ブラウザで [http://localhost:3000](http://localhost:3000) を開く
